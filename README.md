# 물류 로봇 3D 배치 에디터

React + TypeScript + Babylon.js로 만든 첫 버전입니다. 미터 단위의 30 × 30 m 바닥, 0.5 m 그리드, GLB 로봇 선택, XZ 이동과 Y축 회전, JSON 저장·복원을 지원합니다. 경로 재생과 성능 비교는 후속 범위입니다.

## 실행

Node.js 22 이상을 권장합니다.

```sh
npm install
npm run dev
```

터미널에 표시된 주소(기본 http://localhost:5173)를 브라우저에서 엽니다. 클라우드에서는 해당 포트를 전달해 접속하세요. WebGL을 사용할 수 있는 브라우저가 필요합니다.

```sh
npm run build   # 타입 검사 + 배포용 dist 생성
npm test        # JSON 복원, 입력 오류, 스냅 검증
npm run preview # 빌드 결과 확인
```

## 첫 버전 검증 절차

1. **로봇 추가**를 누릅니다. 원점에 로봇이 나타나고 속성 패널에 ID와 모델이 표시됩니다.
2. 빈 바닥을 드래그하여 카메라를 회전하고, 휠로 확대·축소합니다. 로봇을 클릭하면 선택됩니다.
3. **이동**에서 X/Z 화살표 또는 바닥 평면 핸들을 드래그합니다. 마우스를 놓으면 좌표가 0.5 m 배수인지 확인합니다. Y는 0입니다.
4. **회전**을 선택하고 원형 핸들을 드래그합니다. 마우스를 놓으면 Y축 각도가 15° 배수인지 확인합니다. 주황색 표시가 전면입니다.
5. 정확한 비교를 위해 패널에 X=2.5, Z=-3, 회전=75를 입력합니다. ID와 값을 기록하고 **JSON 저장**을 누릅니다.
6. 새로고침합니다. 빈 장면이 나오는 것을 확인한 뒤 **JSON 불러오기**에서 다운로드한 파일을 고릅니다.
7. 같은 ID, 모델, X=2.5, Y=0, Z=-3, 회전=75와 같은 배치를 확인합니다. 카메라 시점은 저장 대상이 아닙니다.
8. 잘못된 JSON 또는 중복 ID를 가진 파일을 불러오면 오류가 표시되고 기존 배치가 유지되는지 확인합니다.

추가된 로봇은 모두 원점에서 시작하므로 여러 개를 추가할 때는 먼저 이동시키세요. 파일을 불러오면 현재 배치 전체를 교체합니다. 자동 저장은 하지 않습니다. 최대 100개까지 허용하지만 이 숫자는 성능 보장치가 아닙니다. 기즈모 드래그 중에는 씬이 직접 움직이고, 드래그 종료 시 React 데이터와 패널에 반영합니다.

## 데이터와 코드 구조

- `src/layout.ts`: 저장 가능한 Robot/Layout 타입, JSON 검증, 스냅 계산
- `src/scene.ts`: 엔진, 씬, 카메라, 모델 로딩, 메시, 기즈모의 수명 관리
- `src/main.tsx`: React 도구 모음, 선택 ID, 로봇 배열, 속성 패널, 파일 입출력
- `public/models/warehouse-amr.glb`: 이 프로젝트에서 제작한 기본 AMR 모델
- `scripts/generate-model.py`: 외부 패키지 없이 기본 GLB를 재생성하는 스크립트
- `docs/3d-glossary.md`: 프론트엔드 개발자를 위한 용어 정리

React의 로봇 배열이 배치 데이터의 기준입니다. Babylon 객체는 Map으로 ID에 연결하며 JSON에 넣지 않습니다. 이 버전은 Babylon 기본 왼손 좌표계를 사용하며 Y가 높이입니다. 회전은 파일에서 도(degree), Babylon에서는 라디안으로 변환합니다. 모델은 glTF 로더가 좌표계를 변환하므로 로봇용 부모 TransformNode에 배치 변환을 적용합니다.

```json
{
  "version": 1,
  "robots": [
    {
      "id": "robot-1",
      "model": "warehouse-amr",
      "position": { "x": 2.5, "y": 0, "z": -3 },
      "rotation": { "y": 75 }
    }
  ]
}
```

불러오기는 유효한 위치·방향을 그대로 복원합니다. 외부에서 만든 파일에 스냅 간격 밖의 값이 있더라도 강제로 반올림하지 않습니다. 편집 시에는 스냅이 적용됩니다. 모델 키는 현재 `warehouse-amr`만 허용하며 임의 URL을 실행하거나 불러오지 않습니다.
